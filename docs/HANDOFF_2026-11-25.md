## 2. Rules the user set (keep them)

- **CI:** keep CI and lint green. Merge a PR only after its CI passes. Never use `gh pr merge --auto` (the repos have auto-merge off, so it merges immediately).
- **Commits:** `type(scope): lowercase subject`, a short body explaining why, ending with the `Co-Authored-By` line. PR bodies end with the Claude Code line.
- **Secrets:** never read or print `.env` files. Credentials are loaded only by the programs themselves.
- **Trading:**
  - Never place live or real-money orders.
  - Paper trading (Alpaca paper account, fake money) is fine when the user asks.
  - Never give personal investment advice.
- **Spending:** paid API calls (OpenAI) need the user's OK each time. The user approved one AlphaSignal re-embedding on 24 Nov (~$0.40).
- **Data:** never write test or fake data into real data folders (`AlphaSignal/data`, AlphaLab's cache).
